# SevaSetu AMC UI

Mobile-first React and Vite interface for tenant-based AMC sales, service packages, billing, customer reminders, and administration.

## Development

```bash
npm ci
npm run dev
```

The Vite development server proxies `/api` to `http://localhost:8080`.

## Production build

```bash
npm ci
npm run build
```

The production output is written to `dist/`.
